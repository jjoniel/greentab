# GreenTab

Browse lighter — less carbon, less waste, less bloat.

A Chrome extension for carbon-aware browsing: AI-free search, ad blocking, autoplay off, tab sleeping, lazy images, and a live footprint tracker.

## Features

- **AI-free search** — Redirects to Google's udm=14 for pure web results (no AI overviews)
- **Ad & tracker blocking** — Declarative network rules to cut bloat
- **Autoplay blocking** — Stops videos from auto-playing
- **Tab sleeping** — Suggests closing idle tabs, sleeps inactive ones
- **Lazy images** — Adds `loading="lazy"` to below-fold images
- **Footprint tracker** — Tracks CO₂ saved, water bottles equivalent, and AI site impact

## Install

1. Clone or download this repo
2. Open `chrome://extensions`
3. Enable "Developer mode"
4. Click "Load unpacked" and select the extension folder

## Usage

- **New tab** — Shows your impact stats, search, and open tabs
- **Settings** — Top right gear to toggle features
- **Impact sidebar** — Left side shows CO₂ saved, autoplays stopped, tabs slept, and footprint
